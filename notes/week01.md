# 第 1 周：Linux 基础命令

## 今天练过的命令

| 命令 | 作用 |
|---|---|
| `pwd` | 显示当前目录 |
| `ls -la` | 列出全部文件（含隐藏文件） |
| `cd` | 切换目录 |
| `mkdir` | 新建目录 |
| `touch` | 新建空文件 |
| `cp` / `mv` / `rm` | 复制 / 移动 / 删除 |
| `cat` | 查看文件内容 |
| `echo "x" > a.txt` | 写入文件 |
| `df -h` | 磁盘占用 |
| `free -h` | 内存占用 |
| `ps aux` | 查看进程 |
| `top` | 实时进程（按 q 退出） |
| `man ls` | 查看手册（按 q 退出） |

## 踩坑记录

- Linux **区分大小写**：`Readme.md` 和 `readme.md` 是两个文件
- `/` 是根目录，`~` 是当前用户家目录（`/home/zhengpf`）
- `rm` 不进回收站，删之前先用 `ls` 确认
- Windows 的盘挂在 `/mnt/c`、`/mnt/d`，在 WSL 里可以直接访问

## 下次要学

- 文件权限：`rwx`、`chmod`、`chown`
- 管道与重定向：`|`、`>`、`>>`
- 进程管理：`ps`、`kill`、`systemctl`
