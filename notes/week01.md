## 2026-11-15 进阶（第 2 天）

### 文件操作

| 命令 | 作用 | 关键点 |
|---|---|---|
| `touch` | 建空文件 | 文件已存在只更新时间 |
| `cp` / `cp -r` | 复制 | 复制目录必须 `-r` |
| `mv` | 移动 / 改名 | 同目录下 = 改名 |
| `rm` / `rm -r` | 删除 | 删目录必须 `-r`；不进回收站 |
| `cat` | 查看全文 | 适合小文件 |
| `more` / `less` | 分页查看 | less 更好用（可回翻、可搜索） |
| `head -n` / `tail -n` | 看头 / 尾 N 行 | — |
| `tail -f` | 实时跟踪文件 | 看日志、看串口输出必用 |

### 查找

| 命令 | 作用 | 例子 |
|---|---|---|
| `find` | 按名字/类型/时间找 | `find ~ -type d -name "week*"` |
| `which` / `type` | 查命令位置 | `which cd` 无结果因为它是内置命令 |
| `grep` | 按内容找行 | `grep -rn "error" .` |
| `wc` | 统计 | `wc -l` 行 / `-w` 词 / `-c` 字节 / `-m` 字符 |

### 组合技

| 符号 | 作用 | 例子 |
|---|---|---|
| `\|` | 管道：输出喂给下一个命令 | `cat lhc.txt \| grep lhc \| wc -l` |
| `>` | 覆盖重定向（**会清空原文件**） | `ls > list.txt` |
| `>>` | 追加重定向 | `echo "新行" >> list.txt` |
| `` `命令` `` / `$(命令)` | 命令替换 | `echo $(pwd)` |

## 踩坑记录（都是今天真实遇到的）

- **`echo`pwd`` 报错**：命令和参数之间必须留空格
- **`wo xxx >> file` 报 command not found**：重定向不产生文字，必须用 `echo`
- **`tail test.txt` 找不到**：文件名拼错（实际是 `test1.txt`），先 `ls` 再敲
- **`grep "lhc" .` 报 Is a directory**：搜目录要加 `-r`
- **`cp -p dir1 dir2` 报 -r not specified**：`-p` 是保留属性，递归是 `-r`
- **`cd ~/zhengpf` 报错**：`~` 本身就是 `/home/zhengpf`，不能再套一层
- **在 `/` 下 `mkdir` 报 Permission denied**：根目录属主是 root，普通用户只能读
- **`su - root` 一直失败**：Ubuntu 的 root 默认无密码，要用 `sudo`
- **`wc` 的输出顺序固定**：按 `l → w → m → c`，与参数书写顺序无关
- **中文一个字符占 3 字节**：所以 `wc -m`（91）和 `wc -c`（111）不相等
